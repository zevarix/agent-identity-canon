# Identity history

Current canon answers who the agent is **now**. This directory exists so evolution does not require silently rewriting the past.

Record meaningful transitions when a current identity field is `refined`, `superseded`, or `retired`.

Use [`../templates/history-entry.yaml`](../templates/history-entry.yaml) as a starting point.

A history event should preserve a stable event ID, date/context, module and field, outcome, previous record, current record when applicable, concise reason, and evidence/provenance pointer when useful.

History is context, not current canon. The active module remains authoritative for the current value.
